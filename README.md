# Watt The Cell

Watt The Cell is a project for generating a demo manufacturer Verifiable Credential (VC).

The goal is to create a sample credential representing a manufacturer for use in demonstrations and integration testing.

## Demo scope

The credential is intended to use fictional manufacturer data. It is a demonstration artifact and does not certify a real manufacturer's identity or qualifications.

## Project status

This repository currently contains the project documentation. Implementation and usage instructions will be added as the generator is developed.
